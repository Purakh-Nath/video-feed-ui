# Video Feed UI

This is a simple React application that displays a feed of videos fetched from a public YouTube API. The app shows video thumbnails and titles in a grid layout.

## Features

- Fetches video data from a public API (https://freeapi.app/)
- Displays videos in a responsive grid
- Uses dark theme with Tailwind CSS
- Shows loading state while fetching data

## Technologies Used

- React 19
- Vite
- Tailwind CSS
